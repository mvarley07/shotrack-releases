# ShotRack releases

ShotRack is a Mac menu bar app that collects screenshots, code and error messages as you work, then pastes them all at once into Claude or wherever you need them. It also connects to Claude Desktop, so Claude can pull your rack directly.

**Website and download:** https://www.shotrack.app

This repo hosts ShotRack's release builds and the update manifest the app checks for new versions. ShotRack runs on Apple silicon Macs.
